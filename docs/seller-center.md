# 賣家工作台與前台購物改進

## 上架與庫存

1. 在「商品管理」新增草稿、填寫價格與說明，上傳圖片並指定主圖。主圖會優先出現在前台。
2. 查看「上架檢查」欄位，確認缺少的介紹、圖片與分類狀態。這是資料完整性提醒；圖片不會被自動產生或替換。
3. 使用「前台預覽」檢查草稿。只有有商品編輯權限的後台人員能預覽，預覽模式無法購買。
4. 選取商品使用批次發佈、下架或推薦。售價須大於零且分類已啟用才能批次發佈。
5. 複製商品會產生新 SKU、保留圖片與介紹、改為草稿並將庫存歸零。請填入實際庫存後才上架。
6. 在商品清單選取商品，使用「補貨／耗損：批次調整庫存」。正數補貨、負數扣除，每件商品各加減同一數量，必填原因。任何一件庫存不足則整批回復。調整前後數量與原因可在商品「歷史」查閱；收藏者仍會收到補貨站內通知。

## 每日出貨

入口：後台側欄「訂單與物流 → 出貨工作台」，或 `/admin/plus/order/fulfillment/`。

- 狀態分頁：待出貨、待付款、運送中、已完成、取消／退款、全部訂單。
- 搜尋訂單編號、收件人、電話或物流單號。待出貨依成立時間由舊至新排列。
- 勾選訂單後可列印「彙總揀貨單＋每筆裝箱單」，或匯出包含商品 SKU、數量與配送備註的 CSV。匯出包含個資，依原有訂單檢視權限管制，避免快取且處理試算表公式字元。
- 「開始備貨」將訂單設為處理中。物流商與單號在確認出貨時一併儲存。
- 填妥每筆物流商、物流單號，勾選後「確認批次出貨」。每次最多 100 筆；目前畫面每頁 25 筆。任何一筆不符條件，整批不變更，並保留本頁輸入供修正。
- 線上付款須已付款；貨到付款可在尚未收款時備貨與出貨。取消、退款、完成或有進行中售後的訂單不允許出貨。
- 訂單處理紀錄保存操作者與時間。前台只顯示狀態與時間，不公開員工身份。
- 列印文件只用於揀貨及包裹核對，不會取得物流商託運編號，也不是物流寄件標籤。物流寄件 API、即時貨態、電子發票開立及實際金流退款須另以正式供應商整合驗收。

訂單內容、原始金額與商品快照禁止直接改寫或刪除；付款後的取消須透過售後處理。後台退款狀態代表管理者登記退款結果，並不會呼叫金流退款 API。

## 前台

- 商品專區新增品牌形象區、配送／售後／客服入口，重新整理搜尋、分類、商品卡片與手機兩欄呈現。
- 篩選條件顯示為可移除標籤；翻頁保留品牌、價格、庫存與搜尋條件，網址正確編碼。
- 熱銷依有效已付款訂單的購買數量排序，排除取消與退款。
- 我的訂單支援進度分頁、數量、訂單編號或商品名稱搜尋，資料限定登入會員本人。
- 貨到付款不再顯示前往線上付款；取消與退款訂單不顯示誤導性的正常配送進度。
- 修正缺少預設圖片及主圖順序、允許手機縮放、補上搜尋欄標籤與鍵盤焦點樣式。

## 更新與驗證

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
.venv/Scripts/python.exe manage.py migrate
.venv/Scripts/python.exe manage.py check
.venv/Scripts/python.exe manage.py makemigrations --check --dry-run
.venv/Scripts/python.exe -m pytest
```

新增遷移 `0026`（訂單處理紀錄）與 `0027`（商品主圖排序）。既有訂單不捏造歷史紀錄；既有時間戳仍顯示於訂單頁。正式部署仍需執行 `collectstatic`；若環境另指定 `STATIC_VERSION`，請同步更新快取版本。

自動化涵蓋出貨交易回復、付款與角色限制、重複操作、取消還庫存與優惠券、CSV、庫存稽核、草稿預覽、商品複製、主圖、篩選分頁及會員資料隔離。另以獨立 SQLite 副本在 Edge 檢查 1440px／390px 版面，走訪客快速預覽加入購物車、填單出貨、列印清單與查訂單。

## 交付範圍

這次完成購物呈現、商品維護及出貨作業的改進，並非金流／物流業者的正式上線驗收。商品多規格 SKU、批次商品檔案匯入、供應商採購、物流寄件 API 與自動退款等不包含在本次實作。

目前根目錄 `LICENSE` 仍為禁止商用與正式上線的教材授權。若要出售或商用，須先由權利人處理授權，並確認商品圖文素材及正式整合可供商業使用。本次未改變授權或部署正式站。
